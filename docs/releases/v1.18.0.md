**Release Date:** 2026-11-10

PulseScribe 1.18.0 – Live text for local dictation

**See your words while you speak (Apple Silicon).** Local dictation with the MLX backend, the default on Apple Silicon, now shows the recognized text in the overlay during the recording, updated about every 0.7 seconds. Until now only Deepgram showed live text. The last word appears once the next one follows or you pause.

**Same transcript, often sooner.** The final text is unchanged: it is still one pass over the whole recording. If you pause for about a second before you stop, the transcript is ready at once instead of after about 0.4 seconds (M6, turbo, recordings up to 20 seconds in a quiet room), because the pause already ran that pass. If you stop within a tenth of a second of your last word, a running preview pass can delay the transcript by up to 0.3 seconds.

**Turn it off if you prefer.** Settings → Providers → Advanced backend options → Live preview. While you speak, the GPU works for roughly half of the time. Recordings longer than 20 seconds preview only their newest part, and other local backends are too slow for a preview.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.18.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.18.0-Local.zip`.
