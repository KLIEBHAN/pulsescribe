**Release Date:** 2026-11-17

PulseScribe 1.21.1 – Long recordings with Parakeet and Canary

**Canary no longer returns an empty transcript for long recordings.** In 1.21.0 Canary-1B-v2 gave no text for recordings longer than about 37 seconds; it was trained on pieces of at most 40 seconds. Parakeet v3 handled them but dropped words: on five minutes of German speech, 29 % of the words were wrong.

**Recordings longer than 15 seconds are now transcribed in pieces.** Each piece is at most 15 seconds long and cut at the quietest moment of its last five seconds, so words are not split. On the same five-minute recording, 0.1 % of the words were wrong with Parakeet and 2.0 % with Canary. Shorter recordings are unchanged.

Whisper models are not affected.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.21.1.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.21.1-Local.zip`.
