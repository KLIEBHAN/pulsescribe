**Release Date:** 2026-11-10

PulseScribe 1.19.0 – Live text you can read

**Two lines instead of a jumping one (macOS).** Recordings with live text (local dictation with turbo, Deepgram streaming) now open a larger overlay with two lines of text. Until now the overlay showed one short line with about the last 35 characters, which jumped with every update.

**Words keep their place.** While the text grows, a word stays where it appeared; when the lines are full, the upper one scrolls out as a whole. If a word is corrected, only the text after it moves.

**Bright means confirmed.** Words that were already shown are bright. New words are dimmed until the next update confirms them; a finished sentence is bright as a whole.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.19.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.19.0-Local.zip`.
