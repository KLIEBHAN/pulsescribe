**Release Date:** 2026-11-11

PulseScribe 1.20.3 – Local Whisper about twice as fast on current macOS

**Local transcription takes about half the time on macOS 26.2 and newer.** MLX, the library that runs Whisper on the GPU, comes in one build per macOS generation. The app was built on macOS 15 and shipped the build for it, which runs much slower on current macOS than the build made for it. The app now carries both and loads the one for your system. Measured with the turbo model, same MLX files outside the app: on an M5 a pass over 2 seconds of audio takes 0.34 s instead of 0.77 s and over 12 seconds 0.46 s instead of 0.87 s; on an M6 0.28 s instead of 0.60 s. The transcripts were identical in all 15 comparisons.

**Where you notice it.** The wait after you stop mid-sentence is one Whisper pass, so it shrinks by the same amount. The live preview with Whisper and the background passes of the streaming preview stay well below their one-second limit, which they came close to before.

**Older macOS is unchanged.** macOS 15 to 26.1 keep the build they had; the faster one needs macOS 26.2. The log names the build when the model loads, for example `MLX-Build: mlx_macos26 (macOS 26.2+)`.

**The download is larger.** The DMG grows from 272 MB to 363 MB because it contains MLX's native code twice.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.20.3.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.20.3-Local.zip`.
