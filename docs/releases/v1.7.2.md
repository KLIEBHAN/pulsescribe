**Release Date:** 2026-10-28

PulseScribe 1.7.2 – Preserved drafts and calmer macOS feedback

**Windows keeps unsaved editor drafts.** Returning to Vocabulary no longer replaces your edits when its saved file changed in the meantime. Reload from File asks before discarding changes. Restoring a saved custom prompt to its default leaves the Save button enabled until you save the reset.

**The macOS overlay does less idle work.** Once silent audio levels and the bars have settled, the recording-level animation timer pauses. New audio resumes rendering at the existing rate; recording and transcription are unchanged.

**Success feedback remains visible while you are ready to dictate again.** The brief macOS confirmation is no longer hidden by the immediate return to ready. A new recording replaces it without waiting, and feedback animations stop when the overlay hides.

**Manual macOS updates can retry after a launch failure.** If opening the downloaded installer fails, its verified package returns to staging for another attempt. Existing files in Downloads are preserved. Package validation also retries transient busy-volume detach errors without forcing an unmount or weakening validation.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.7.2.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.7.2-Local.zip`.
