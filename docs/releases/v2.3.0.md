**Release Date:** 2026-11-28

PulseScribe 2.3.0 – Expanded local open-source ASR catalog

**Parakeet Ultra 0.6B (`parakeet-ultra`, alias `parakeet`).** Moondream's post-trained `parakeet-tdt-0.6b-v3` (`int8`, 671 MB, 25 European languages, CC-BY-4.0) runs on the existing `sherpa-onnx` CPU backend with the same latency as `parakeet-v3` while improving German accuracy and noise robustness. Existing `parakeet-v3` configurations stay untouched.

**Cohere Transcribe 2B (`cohere-transcribe`).** Cohere's 14-language Conformer-Transformer (`int8`, 2.89 GB, Apache 2.0) brings punctuation, inverse text normalization, and per-stream language switching via `sherpa-onnx` without reloading model weights.

**Qwen3-ASR 0.6B (`qwen3-asr-0.6b`) with `vocabulary.json` hotwords.** Alibaba's 30-language offline model (`int8`, 987 MB, Apache 2.0) supports per-stream custom vocabulary biasing on CPU alongside safe nested-directory model downloads (`tokenizer/*`).

**Whisper Large v3 Turbo German (`large-v3-turbo-german`).** `primeline`'s German Whisper Turbo fine-tune (`Q5_0`, 574 MB, Apache 2.0) runs directly on `whisper-rs` (Metal on Apple Silicon / CPU on Windows) with full `vocabulary.json` prompting.

### Install / Update

- **Automatic in-app update (v2.2.0+):** Installed PulseScribe `v2.2.0` builds detect `v2.3.0` automatically and offer **Restart & Install** from the tray menu or **Settings → Diagnostics**.
- **macOS (Apple Silicon):** Download `PulseScribe-2.3.0-macOS-arm64-Full.dmg` (local + cloud) or `PulseScribe-2.3.0-macOS-arm64-Slim.dmg` (cloud-only), verify `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-2.3.0-macOS-arm64-Full.dmg`), quit PulseScribe, and copy `PulseScribe.app` into `/Applications`. Signed with the pinned PulseScribe certificate so macOS permissions carry over across updates; verify the signature before clearing quarantine on a first install:

  ```bash
  codesign --verify --deep --strict /Applications/PulseScribe.app
  xattr -dr com.apple.quarantine /Applications/PulseScribe.app
  ```

- **Windows (x64):** Download `PulseScribe-2.3.0-Windows-x64-Full-Setup.exe` (local + cloud) or `PulseScribe-2.3.0-Windows-x64-Slim-Setup.exe` (cloud-only) and run the per-user installer.
