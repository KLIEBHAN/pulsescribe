**Release Date:** 2026-10-13

PulseScribe 1.6.1 – Permissions stay granted after updates

On macOS, Microphone, Accessibility and Input Monitoring now stay granted after future updates.

After this update, macOS asks for these permissions one last time.

<!-- install-notes -->

Releases are now signed with a stable PulseScribe certificate. Until now, macOS identified the ad-hoc signed app by the hash of each build, so every update counted as a new app. Now macOS identifies it by its certificate, which stays the same.

After updating to 1.6.1, grant the permissions again in System Settings → Privacy & Security. If PulseScribe is listed under Accessibility or Input Monitoring but does not work, remove it with the minus button and add it again. Alternatively, reset all of its permissions and grant them at the next start:

```bash
tccutil reset All com.kliebhan.pulsescribe
```

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.6.1.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app is not notarized. Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.6.1-Local.zip`.
