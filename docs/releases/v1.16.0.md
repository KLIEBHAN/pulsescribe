**Release Date:** 2026-11-04

PulseScribe 1.16.0 – Clearer advanced options

**Only options that work.** Settings → Providers → Advanced backend options now show only what the active local backend uses, on macOS and Windows. With MLX, the default on Apple Silicon, Device and Beam size are gone (MLX always runs on the GPU and has no beam search); with faster-whisper, FP16 is gone. Every option has a tooltip that says what it does and what "default" means. Windows gains the Fast option.

**Checked values and a reset.** Typed values are checked on save: Beam size 50 or a temperature of `0,5` (German decimal comma, which was read as the two values 0 and 5) no longer get saved; PulseScribe names the field instead. **Reset to defaults** puts all advanced options back without touching backend and model.

**Unload when idle (macOS).** The local model can now free its memory after 5, 15, 30 or 60 minutes without dictation (turbo 8-bit: about 0.8 GB). The next recording starts loading it right away, so it loads while you speak. Default: never.

**Fixes.**
- Windows: with backend "auto", the faster-whisper options (Compute type, CPU threads, VAD filter) are reachable again.
- Windows: the temperature field accepts fallback lists like `0.0,0.2,0.4`, as documented.
- macOS: the Device list no longer offers CUDA.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.16.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.16.0-Local.zip`.
