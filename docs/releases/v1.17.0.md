**Release Date:** 2026-11-04

PulseScribe 1.17.0 – Release history in settings

**What's new, inside the app.** Settings → About → What's new now shows the five newest releases shipped with your installation, with their version and date, on macOS and Windows. Scroll through the notes or select and copy the text. Installation instructions are left out.

**Available offline.** The notes are bundled with the app and loaded only when you first open About. Opening other settings does not read the release files or contact GitHub. To check for a newer version, use **Check for Updates…** as before.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.17.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.17.0-Local.zip`.
