**Release Date:** 2026-11-10

PulseScribe 1.20.0 – Word-by-word live text

**Live text that keeps up with you (macOS).** Settings → Providers → Advanced backend options → Live preview has a new choice, **streaming model**. A second speech model then shows each word about 0.6 seconds after you say it, in steps of half a second. It runs on the CPU beside Whisper, so it works with every local model and backend, including large-v3. In our measurements it did not delay the transcript.

**Whisper still writes the transcript.** The streaming model only feeds the overlay. Its text is rougher than Whisper's: on German test recordings 8 to 11 % of the words were wrong (Whisper turbo: 5 %), and numbers come as words. What gets pasted is unchanged.

**What it costs.** A one-time download of 0.7 GB after you save the choice, about 1.9 GB of memory while the model is loaded and about a third of one CPU core while you speak. **Unload when idle** frees the memory together with the Whisper model. The streaming model is not selected by default; "on" remains the Whisper preview from 1.18.

**The option shows for every local backend.** It no longer hides for large models. A line above the options says what the streaming model costs, or why "on" shows no text with a large model.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.20.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.20.0-Local.zip`.
