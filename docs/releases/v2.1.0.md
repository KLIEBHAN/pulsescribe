**Release Date:** 2026-11-23

PulseScribe 2.1.0 – German interface language, native macOS menu bar icon, and Rust-only codebase

**Selectable interface language (System / English / Deutsch).** Choose your preferred interface language under **Settings → General → Interface → Interface Language** (defaults to your OS locale). Switching applies immediately across all desktop views, dialogs, daemon status messages (including clipboard/paste recovery hints), and the native macOS menu bar / Windows system tray without restarting.

**Native macOS monochrome menu bar icon.** PulseScribe now renders a dedicated Retina monochrome template icon in the macOS menu bar that matches standard macOS status bar icons and adapts automatically to light, dark, and translucent menu bars. Windows keeps the full-color tray icon.

**Rust-only codebase.** Removed the retired Python 1.x implementation, legacy packaging scripts, and Python CI workflows while keeping all Rust contract tests and configuration compatibility (`~/.pulsescribe/`) intact.

### Install / Update

- **macOS (Apple Silicon):** Download `PulseScribe-2.1.0-macOS-arm64-Full.dmg` (local + cloud) or `PulseScribe-2.1.0-macOS-arm64-Slim.dmg` (cloud-only), quit PulseScribe, and copy `PulseScribe.app` into `/Applications`. Signed with the pinned PulseScribe certificate so macOS permissions carry over across updates. Verify `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-2.1.0-macOS-arm64-Full.dmg`) and, on a first install, clear quarantine if needed:

  ```bash
  xattr -dr com.apple.quarantine /Applications/PulseScribe.app
  ```

- **Windows (x64):** Download `PulseScribe-2.1.0-Windows-x64-Full-Setup.exe` (local + cloud) or `PulseScribe-2.1.0-Windows-x64-Slim-Setup.exe` (cloud-only) and run the per-user installer.
