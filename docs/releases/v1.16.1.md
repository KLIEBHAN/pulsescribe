**Release Date:** 2026-11-04

PulseScribe 1.16.1 – Sounds play once, taller wave

**macOS sounds play once.** The first start, stop, done or error sound after launch no longer plays twice. Later sounds use the fast system player again instead of the slower `afplay` fallback, so they come right on cue.

**Taller recording wave.** While you speak, the wave in the overlay now reaches up to 30 px instead of 24 px, on macOS and Windows. The listening row before a recording is unchanged.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.16.1.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.16.1-Local.zip`.
