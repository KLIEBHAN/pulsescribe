**Release Date:** 2026-11-11

PulseScribe 1.20.2 – Shorter paste confirmation

**The "Pasted" confirmation clears sooner (macOS).** After a transcription the overlay could cover the spot where the text had just been pasted. It now stays 0.5 s instead of 0.8 s before it fades out.

"Copied" and "No speech" stay as long as before. Windows is unchanged; its confirmation was already shorter.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.20.2.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.20.2-Local.zip`.
