**Release Date:** 2026-11-17

PulseScribe 1.22.1 – Unload when idle stays reliable with future MLX versions

**Unloading a local model keeps freeing its memory.** PulseScribe freed MLX memory through a call that MLX has marked as outdated. Had MLX removed it, a model unloaded by **Unload when idle** would have kept its memory, 1.4 GB with Canary. PulseScribe now uses the current call and falls back to the old one on older MLX. After unloading Parakeet or Canary the whole app uses about 90 MB again; macOS returns the memory within about two seconds.

Nothing else changes; this version shows no outdated-call warning in the log any more.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.22.1.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.22.1-Local.zip`.
