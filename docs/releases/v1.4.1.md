**Release Date:** 2026-10-13

PulseScribe 1.4.1 – Reliable in-app updates

Fixes secure update checks on packaged macOS apps whose host has no Python certificate installation. The updater now uses the CA bundle already shipped with the app while preserving certificate verification, hostname checking and host trust.

Includes the 1.4 update system: installed apps check stable GitHub releases in the background, download the matching platform package, verify its size and SHA-256, and show release notes before a confirmed restart when dictation has finished. Use “Check for Updates…” in the macOS menu bar or Windows tray to search manually.

- macOS replaces writable installed apps after orderly exit and restores the previous bundle if the replacement fails. Read-only locations open a manual installer in Downloads.
- Windows preserves the installation directory and machine/current-user mode. Local Whisper installations require their matching optional package and never receive the API-only installer.
- Settings, prompt editing, history and status displays perform less repeated work, and packaged apps use the refreshed PulseScribe icons.

Install 1.4.1 once from this release if you are using 1.3.0 or earlier, or if macOS 1.4.0 reports a certificate error while checking for updates. Windows 1.4.0 can install this release from its tray menu. Configuration in ~/.pulsescribe is preserved.

The macOS app is ad-hoc signed and not notarized; the Windows installer is unsigned. Use the existing Gatekeeper/SmartScreen installation steps. macOS may ask for accessibility permission again after the app is replaced. The larger Windows Local Whisper package remains an optional separate build.
