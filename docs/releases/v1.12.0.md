**Release Date:** 2026-11-03

PulseScribe 1.12.0 – Transcribe on your own server

**Own transcription server.** The new mode `openai_compatible` sends each recording to your own server that offers OpenAI's transcription API, for example a Whisper server on another computer in your network. Choose it in Settings → Providers and enter the Server URL (such as `http://mac-mini:7860/v1`). The text arrives after you stop recording; your OpenAI key is never sent to that server. If your server checks a key, set `OPENAI_COMPATIBLE_API_KEY` in `~/.pulsescribe/.env`; plain `http://` is unencrypted, so use it only in a trusted network.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.12.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.12.0-Local.zip`.
