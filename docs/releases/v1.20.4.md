**Release Date:** 2026-11-11

PulseScribe 1.20.4 – Paste confirmation shorter again

**The "Pasted" confirmation clears sooner (macOS).** It now stays 0.3 s instead of 0.5 s before it fades out, so it covers the freshly pasted text for less time.

"Copied" and "No speech" stay as long as before. Windows is unchanged.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.20.4.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.20.4-Local.zip`.
