**Release Date:** 2026-11-02

PulseScribe 1.10.0 – A steadier, more helpful overlay

**The overlay keeps its shape while you dictate.** It stays 400 px wide from listening to the result, and status, text and details each have a fixed place, so nothing jumps between states. While you speak, the newest words stay visible and older ones fade out on the left.

**You see how long you have been recording.** The overlay shows the time in `m:ss`, updated once per second, so a running recording is easy to notice.

**Refine shows its progress.** When Refine follows transcription, a two-part line shows "1 of 2" while transcribing and "2 of 2" while refining.

**The result tells you where the text went.** After a paste the overlay names the target app, for example "into Mail" (on Windows the program name). With **Show transcription time after each result** turned on, it shows how long transcription took, such as "1.2 s", instead of the real-time factor.

**Errors point to the fix.** When pasting fails, the overlay says "Copied — press ⌘V" (Windows: Ctrl+V). "Missing API key" and "Microphone unavailable" show a **Settings** link that opens Settings on Transcription. On macOS the overlay no longer says "Pasted" when the text was only copied.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.10.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.10.0-Local.zip`.
