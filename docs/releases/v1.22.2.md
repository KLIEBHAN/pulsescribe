**Release Date:** 2026-11-17

PulseScribe 1.22.2 – Fast first dictation with Parakeet and Canary

**The first dictation after loading Parakeet or Canary is fast too.** On the GPU, the first dictation after loading the model could take up to 0.9 seconds instead of about 0.05 seconds. Loading now runs one short pass over a second of silence in the background, as Whisper on the GPU already does, so the first dictation is as fast as the following ones. Loading takes about 0.6 seconds instead of 0.2; you can dictate meanwhile.

Nothing changes on the CPU or with Whisper.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.22.2.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.22.2-Local.zip`.
