**Release Date:** 2026-11-04

PulseScribe 1.15.0 – Leaner local transcription

**Download progress.** The first time a local MLX or faster-whisper model is loaded, the menu bar (macOS) or tray (Windows) shows how far the download is, for example "43 % · downloading turbo (1.6 GB)". Before, PulseScribe only showed "Loading…" for the minute a large model can take.

**8-bit MLX models by default.** On Apple Silicon, local models now run with 8-bit weights: in our German tests as accurate as full precision, about 10 % faster and with roughly half the memory (turbo 0.8 GB instead of 1.5 GB). The large model downloads 1.6 GB instead of 2.9 GB. Settings → Providers → Quantization switches to 4bit or none.

**Smaller macOS app.** The app no longer contains PyTorch, which none of its backends needs: it shrinks from about 1.1 GB to about 0.6 GB.

**Fixes.**
- The local backend "auto" now uses MLX on Apple Silicon. Before, it picked Lightning, which has no turbo model and silently loaded the larger, slower large-v3.
- Settings only offer local backends the app actually contains; a configured backend that is not included falls back to the default instead of failing. The two "macOS: MPS" presets are removed.
- Freeing the local model now also releases the MLX model, which stayed in memory before.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.15.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.15.0-Local.zip`.
