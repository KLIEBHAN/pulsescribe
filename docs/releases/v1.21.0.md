**Release Date:** 2026-11-17

PulseScribe 1.21.0 – NVIDIA Parakeet v3 and Canary-1B-v2 as local models

**Two new local models.** Choose `parakeet-v3` or `canary-1b-v2` under Settings → Transcription → Local Model (or set `PULSESCRIBE_LOCAL_MODEL`). Both come from NVIDIA, run on the CPU through sherpa-onnx whatever local backend is set, know 25 European languages and write punctuation and capitals.

**Parakeet is the fastest local model so far.** On an M5 it transcribed 11 s of German speech in 0.22 s; Whisper turbo with MLX took 0.34 s for the same recording. Canary took 0.65 s. Parakeet detects the language itself. Canary needs it: speech in another language comes out translated into the set one, so with `auto` Canary uses your system language.

**Download and memory.** The first use downloads the model once into the Hugging Face cache, with progress in the menu bar: 0.7 GB for Parakeet, 1.0 GB for Canary. Loaded, they use about 2.1 GB and 2.8 GB of memory; **Unload when idle** frees it.

**What does not apply.** Whisper's options (vocabulary, beam size, temperature, quantization, warmup) have no effect, and Settings hide them. The Whisper live preview (`on`) shows no text with these models; the streaming model does. The Windows installer does not include sherpa-onnx, so the Windows app does not offer the models.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.21.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.21.0-Local.zip`.
