**Release Date:** 2026-11-28

PulseScribe 2.3.1 – Faster, sharper Parakeet Ultra on Apple Silicon & CPU

**Parakeet Ultra PR #4179 mixed-int8 weights (auto-refreshed).** `parakeet-ultra` now ships with the `sherpa-onnx` PR #4179 mixed-int8 encoder (24 depthwise and 5 subsampling convolutions kept in FP32, hosted via `model-parakeet-ultra-pr4179`), cutting Apple M6 CPU latency by ~27–35 % while noticeably improving German and noisy-speech accuracy. Existing `v2.3.0` `parakeet-ultra` caches detect the updated revision via `.pulsescribe-revision` and refresh automatically without re-downloading any other installed models.

**Fast-core CPU threading, silence trimming, and 25 s transducer segments.** Offline `sherpa-onnx` models now target fast (non-`Efficiency`) physical cores by cluster name (e.g. 6 threads on Apple M6 instead of 4, capped at 8), trim dead leading/trailing hotkey silence conservatively (250 ms padding), and segment `parakeet-ultra` / `parakeet-v3` at 25 s instead of 15 s so 15–25 s dictations stay intact without mid-word boundary splits.

### Install / Update

- **Automatic in-app update (v2.2.0+):** Installed PulseScribe `v2.2.0` / `v2.3.0` builds detect `v2.3.1` automatically and offer **Restart & Install** from the tray menu or **Settings → Diagnostics**.
- **macOS (Apple Silicon):** Download `PulseScribe-2.3.1-macOS-arm64-Full.dmg` (local + cloud) or `PulseScribe-2.3.1-macOS-arm64-Slim.dmg` (cloud-only) together with `SHA256SUMS.txt`, verify the DMG checksum (`shasum -a 256 -c --ignore-missing SHA256SUMS.txt`), quit PulseScribe, and copy `PulseScribe.app` into `/Applications`. Signed with the pinned PulseScribe certificate so macOS permissions carry over across updates; verify signature integrity and signer identity before clearing quarantine on a first install:

  ```bash
  codesign --verify --deep --strict /Applications/PulseScribe.app && \
    codesign -dv --verbose=2 /Applications/PulseScribe.app && \
    xattr -dr com.apple.quarantine /Applications/PulseScribe.app
  ```

- **Windows (x64):** Download `PulseScribe-2.3.1-Windows-x64-Full-Setup.exe` (local + cloud) or `PulseScribe-2.3.1-Windows-x64-Slim-Setup.exe` (cloud-only) and run the per-user installer.
