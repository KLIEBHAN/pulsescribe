**Release Date:** 2026-11-02

PulseScribe 1.9.0 – A calmer settings window and overlay

**Settings are organized into six sections.** A sidebar replaces the nine tabs: General, Transcription, Refine, Vocabulary, History and About. Behavior options such as the overlay, clipboard restore and show at startup are under General; History opens on your transcripts. The window is wider and shorter, so it fits smaller screens.

**You see only what applies to your setup.** Transcription shows the API key of the provider you selected, streaming only for Deepgram, and local model options only for Local, with advanced backend options collapsed. Refine shows the key of its own provider and greys out its options while Refine is off.

**A flat, dark look with clear status.** Permissions and API keys show small status badges. The save bar appears only when you have unsaved changes, and a short message confirms saving. On Windows you can discard unsaved changes, and the window stays dark regardless of the system theme.

**The recording overlay is smaller and quieter.** It is 44 px high and monochrome, and only animates while you record. Results appear as small badges: Pasted, No speech, Not pasted or Error. Errors and paste failures now stay on screen with a "×" until you click them or start the next recording.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.9.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.9.0-Local.zip`.
