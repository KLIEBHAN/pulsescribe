**Release Date:** 2026-10-13

PulseScribe 1.5.0 – Windows settings, tray and overlay match macOS

The Windows settings window now follows the macOS layout. All nine tabs fit in
a centered tab bar, dropdowns and checkboxes show their arrows and checkmarks,
and the Setup tab includes the “Try it” card with a shortcut to Hotkeys.
Save & Apply now also saves vocabulary edits, as on macOS, and warns if they
cannot be written.

The Windows tray menu shows the version, current status and a hint, and adds
“Open Log File” and “Export Redacted Diagnostics…”. The recording overlay uses
the macOS size, font and colors. Long live transcripts keep their newest words
instead of being cut off on both sides.

On macOS, the “Try it” card no longer shows “(nicht konfiguriert)” as a hotkey.

Use “Check for Updates…” in the macOS menu bar or Windows tray. For a new macOS
install, copy `PulseScribe.app` to Applications. If macOS blocks the app, run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

The app is ad-hoc signed and not notarized. Configuration in `~/.pulsescribe`
is preserved. The standard Windows installer remains API-only; Local Whisper is
an optional separate package.
