**Release Date:** 2026-11-10

PulseScribe 1.18.1 – Live text with quiet microphones

**Live text at low microphone levels.** In 1.18.0 the live preview showed no text when your voice stayed close to the detection level, for example with a MacBook microphone at low input volume. The preview now follows the level of each recording, so a quiet microphone previews like a loud one.

**Live text needs a fast model.** With `large` and `large-v3` a preview pass takes about a second or longer, too slow for text while you speak. PulseScribe no longer tries with these models, so no preview pass can delay your transcript. Settings hide the Live preview option for them and say why. Choose turbo to see live text.

**No text that stands still.** On a Mac where two preview passes in a row take longer than a second, the preview ends for that recording and removes its text. If it is too slow from the start of a recording, it pauses for 30 minutes.

**Easier to check.** With MLX and the preview on, the log has one `Live-Vorschau:` line per recording: how many passes ran and how long they took, or why none ran.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.18.1.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.18.1-Local.zip`.
