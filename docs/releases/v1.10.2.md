**Release Date:** 2026-11-02

PulseScribe 1.10.2 – See that it hears you

**The overlay shows your microphone level while it listens.** Before you start speaking, the grey bars follow the microphone with a small movement, so you can tell right away that PulseScribe hears you. If they stay flat while you talk, check the selected microphone. Steady room noise keeps them still, and they grow smoothly into the white recording bars once speech is detected.

**Readable app names on Windows.** After a paste, the overlay says "into Microsoft Word" or "into Google Chrome" instead of the process name.

**Settings polish.** The last emoji are gone from the settings, and on macOS the Refine model help and the Permissions section are spaced correctly.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.10.2.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.10.2-Local.zip`.
