**Release Date:** 2026-11-17

PulseScribe 1.22.0 – Parakeet and Canary on the GPU, with live preview

**Parakeet and Canary run on the GPU on Apple Silicon.** They used the CPU before; now they run through MLX, like Whisper. On an M5, 11 seconds of German speech take 0.08 s instead of 0.22 s with Parakeet and 0.22 s instead of 0.65 s with Canary, and both need about half the memory (1.1 GB and 1.5 GB). The text is the same. The first use downloads the GPU version once: 0.7 GB for Parakeet, 1.1 GB for Canary. Intel Macs keep using the CPU.

**Live preview with Parakeet and Canary.** The live preview `on` now works with `parakeet-v3`, and on Apple Silicon with `canary-1b-v2`: the model transcribes the running recording again and again and shows your words while you speak. With Parakeet a pass takes 0.07 s and new text appears about every 0.7 s. If you stop after a pause, the transcript is ready at once. You no longer need the separate streaming model for live text with these models.

The download grows by 5 MB.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.22.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.22.0-Local.zip`.
