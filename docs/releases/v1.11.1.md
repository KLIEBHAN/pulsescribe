**Release Date:** 2026-11-03

PulseScribe 1.11.1 – Polish and fixes

**All messages are in English.** The macOS alerts for a missing or invalid hotkey, hotkey validation messages and vocabulary problems were partly still German.

**Windows fixes.** The overlay no longer misses a live-text update or the clear at the end when the text changes very quickly. In the setup wizard, the Custom hotkey row stays readable with larger system fonts.

**More reliable Windows builds.** The tests for Settings, the setup wizard and the overlay now run on Windows for every change.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.11.1.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.11.1-Local.zip`.
