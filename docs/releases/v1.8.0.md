**Release Date:** 2026-10-30

PulseScribe 1.8.0 – Choose your microphone

**Choose an input device in Settings → Providers → Microphone.** Select your microphone or keep **System default** to use the operating system's input choice. **Refresh** reloads the available devices without opening an audio stream.

**Save & Apply uses the choice from the next recording.** An ongoing dictation is not interrupted. PulseScribe remembers the device name across restarts. If the saved microphone is missing when devices are resolved, automatic input selection is used without discarding your preference. Windows can switch back when the missing microphone becomes available between recordings.

**Device names are stored as data, not configuration syntax.** Apostrophes, quotes and backslashes round-trip through settings. Microphone names are loaded literally instead of expanding environment variables, and settings reject line breaks before changing the saved file.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.8.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.8.0-Local.zip`.
