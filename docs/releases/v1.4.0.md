**Release Date:** 2026-10-13

PulseScribe 1.4.0 – Updates from the app

Installed apps now check for stable releases in the background. Use “Check for Updates…” in the macOS menu bar or Windows tray to search manually. A matching update is downloaded and checked with SHA-256 before installation. The confirmation shows its release notes and offers a restart when dictation has finished.

- macOS replaces the installed app after orderly exit and restores the previous bundle if the replacement fails. Read-only locations open a manual installer in Downloads.
- Windows preserves the installation directory and machine/current-user mode. Local Whisper installations require their matching optional package and never receive the API-only installer.
- Settings, prompt editing, history and status displays perform less repeated work.
- Refreshed app icons use the new PulseScribe SVG artwork.
- Releases now publish their macOS DMG, Windows API-only installer and SHA-256 checksums together after the builds succeed.

Install 1.4.0 once from this release if you are using 1.3.0 or earlier; those versions have no in-app updater. Later releases can be installed from the menu. Configuration in ~/.pulsescribe is preserved.

The macOS app is ad-hoc signed and not notarized; the Windows installer is unsigned. Use the existing Gatekeeper/SmartScreen installation steps. macOS may ask for accessibility permission again after the app is replaced. The larger Windows Local Whisper package remains an optional separate build.
