PulseScribe 2.3.2 – Deterministic local vocabulary correction for all models

**Local post-transcription vocabulary correction.** PulseScribe now automatically applies your `~/.pulsescribe/vocabulary.json` (`keywords`) to plain-text transcripts across all local and cloud models — including `parakeet-ultra`, `parakeet-v3`, `canary-1b-v2`, `cohere-transcribe`, Groq, and OpenAI — right before optional LLM refinement, with ~50 µs overhead and zero configuration changes.

**Precision-first two-tier matching.** Tier 1 fixes casing, word splits, hyphens, and canonical boundary symbols (`Pulsescribe` → `PulseScribe`, `Post Gres QL` → `PostgreSQL`, `Strato 2` → `strato2`, `Whisper RS` → `whisper-rs`, `.Net` → `.NET`) while locking already-canonical phrases of any length. Tier 2 applies conservative German/English phonetic and Damerau-Levenshtein matching for longer domain terms (`Pulses Kriebe` → `PulseScribe`, `Fabian Klipan` → `Fabian Kliebhan`, `Forgeo` → `Forgejo`, `Paraket Ultra` → `Parakeet Ultra`) with strict guards for capitalization, numeric identifiers (`Windows 10` ≠ `Windows 11`), stopwords, and everyday German/English prose.

### Install / Update

- **Automatic in-app update (v2.2.0+):** Installed PulseScribe `v2.2.0` / `v2.3.x` builds detect `v2.3.2` automatically and offer **Restart & Install** from the tray menu or **Settings → Diagnostics**.
- **macOS (Apple Silicon):** Download `PulseScribe-2.3.2-macOS-arm64-Full.dmg` (local + cloud) or `PulseScribe-2.3.2-macOS-arm64-Slim.dmg` (cloud-only) together with `SHA256SUMS.txt`, verify the DMG checksum (`shasum -a 256 -c --ignore-missing SHA256SUMS.txt`), quit PulseScribe, and copy `PulseScribe.app` into `/Applications`. Signed with the pinned PulseScribe certificate so macOS permissions carry over across updates; verify signature integrity and signer identity before clearing quarantine on a first install:

  ```bash
  codesign --verify --deep --strict /Applications/PulseScribe.app && \
    codesign -dv --verbose=2 /Applications/PulseScribe.app && \
    xattr -dr com.apple.quarantine /Applications/PulseScribe.app
  ```

- **Windows (x64):** Download `PulseScribe-2.3.2-Windows-x64-Full-Setup.exe` (local + cloud) or `PulseScribe-2.3.2-Windows-x64-Slim-Setup.exe` (cloud-only) and run the per-user installer.
