PulseScribe 2.0.0 – Native Rust rewrite for macOS and Windows

**Complete native Rust + Tauri v2 desktop app.** PulseScribe 2.0 replaces the Python runtime with a native Rust daemon, audio pipeline, system tray, and 60 FPS overlay (`NSPanel`/`CALayer` on macOS, Direct2D/DirectWrite on Windows). The Settings window uses a lazy WebView that is destroyed on close (0 MB idle WebView RAM), while preserving your existing `~/.pulsescribe/` configuration, prompts, vocabulary, and transcript history 1:1.

**Automatic local model download and preloading.** Local mode supports `whisper-rs` (Metal on Apple Silicon / CPU) as well as `sherpa-onnx` (`parakeet-v3`, `canary-1b-v2`, and optional live `nemotron-streaming` preview). Missing curated models download automatically with live overlay progress (`Downloading …` → `Loading …`) and preload in the background; dictating while a model is still downloading shows progress directly in the overlay and transcribes as soon as the download completes.

**Compact Slim and Full installers.** Both macOS arm64 and Windows x64 ship in two variants: **Full** (cloud + offline local models bundled) and **Slim** (cloud-only, smallest footprint). The macOS Full DMG drops from ~362 MB to ~20 MB.

**Operational improvements.** Rotating file logs (`~/.pulsescribe/logs/pulsescribe.log`), single-instance lock with existing-window activation, native Launch at Login toggle (with Windows autostart migration in the NSIS installer), and SemVer release update checks in Diagnostics → Check for Updates.

### Upgrading from PulseScribe 1.x (Python)

PulseScribe 2.0 is a one-time manual upgrade from 1.x; existing 1.x installations do not auto-upgrade across the runtime rewrite. Your `~/.pulsescribe/` folder (`.env`, API keys, vocabulary, prompts, history) is preserved automatically.

- **macOS (Apple Silicon):** Download `PulseScribe-2.0.0-macOS-arm64-Full.dmg` (or `-Slim.dmg` for cloud-only), quit any running PulseScribe 1.x instance, and copy `PulseScribe.app` into `/Applications`. Because the bundle is signed with the same stable PulseScribe certificate, Microphone, Accessibility, and Input Monitoring permissions carry over. If macOS blocks the first launch, verify `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-2.0.0-macOS-arm64-Full.dmg`) and run:

  ```bash
  xattr -dr com.apple.quarantine /Applications/PulseScribe.app
  ```

- **Windows (x64):** Download `PulseScribe-2.0.0-Windows-x64-Full-Setup.exe` (or `-Slim-Setup.exe` for cloud-only) and run the installer. Any existing legacy `HKCU\...\Run\PulseScribe` autostart entry is migrated automatically.
