**Release Date:** 2026-10-13

PulseScribe 1.4.2 – Fix local MLX transcription on macOS

The macOS app now includes the missing `mlx-whisper` package. This fixes local
model preload failing with “fehlende Abhängigkeit: mlx_whisper”. Full builds now
fail when a local backend dependency is missing, and the packaged app is checked
with real MLX operations and both mel-filter assets before publication.

On macOS, copy `PulseScribe.app` to Applications. If macOS blocks the app, run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

Then open PulseScribe and grant microphone/accessibility permission if prompted.
The app is ad-hoc signed and not notarized.

The verified in-app updater from 1.4.1 is included. Use “Check for Updates…” in
the macOS menu bar or Windows tray. If your older macOS app cannot check for
updates, install this DMG manually once. Configuration in `~/.pulsescribe` is
preserved. The standard Windows installer remains API-only; Local Whisper is an
optional separate package.
