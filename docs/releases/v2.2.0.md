**Release Date:** 2026-11-23

PulseScribe 2.2.0 – Automatic in-app updates for macOS and Windows

**Automatic background update checks & verified downloads.** Installed PulseScribe builds now check GitHub Releases automatically 15 seconds after startup and hourly thereafter, pick the matching installer for your platform and variant (`Slim` or `Full`), and verify download size and SHA-256 checksums over HTTPS-only redirects before preparing the update.

**One-click install & restart.** On macOS, PulseScribe validates the DMG's bundle identifier, version, and code signature (`codesign --verify --deep --strict`), stages the update on the same volume, swaps `PulseScribe.app` atomically with rollback, and relaunches — preserving macOS permissions (or falling back to `~/Downloads` when `/Applications` is not writable). On Windows, PulseScribe runs the silent per-user NSIS updater (`/S /UPDATE`) and relaunches automatically.

**Live status in tray & Diagnostics.** Track checks, download progress, release notes, and **Restart & Install** directly from the menu bar / system tray or **Settings → Diagnostics** in English and German.

> **Upgrading from v2.1.0:** Install `v2.2.0` once manually below; future releases will update automatically in-app.

### Install / Update

- **macOS (Apple Silicon):** Download `PulseScribe-2.2.0-macOS-arm64-Full.dmg` (local + cloud) or `PulseScribe-2.2.0-macOS-arm64-Slim.dmg` (cloud-only), quit PulseScribe, and copy `PulseScribe.app` into `/Applications`. Signed with the pinned PulseScribe certificate so macOS permissions carry over across updates. Verify `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-2.2.0-macOS-arm64-Full.dmg`) and, on a first install, clear quarantine if needed:

  ```bash
  xattr -dr com.apple.quarantine /Applications/PulseScribe.app
  ```

- **Windows (x64):** Download `PulseScribe-2.2.0-Windows-x64-Full-Setup.exe` (local + cloud) or `PulseScribe-2.2.0-Windows-x64-Slim-Setup.exe` (cloud-only) and run the per-user installer.
