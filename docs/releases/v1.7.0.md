**Release Date:** 2026-10-27

PulseScribe 1.7.0 – Copy Last Transcript and clearer paste feedback

The macOS menu bar and Windows tray now include **Copy Last Transcript**. It copies the last dictation of the current session, even if automatic pasting or saving history failed. Transcripts from earlier sessions remain available under Settings → Logs → Transcripts.

Paste feedback now appears after the paste attempt and reports whether the text was pasted, only copied to the clipboard, or could not be copied. A failed delivery no longer plays a success sound. Explicitly copying a transcript is no longer undone by a pending automatic clipboard restore.

Windows installers exclude unused Qt modules. Settings, local presets and transcript-history formatting share simpler code, without changing saved settings or transcript output.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.7.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.7.0-Local.zip`.
