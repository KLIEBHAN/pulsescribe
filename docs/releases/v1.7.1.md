**Release Date:** 2026-10-27

PulseScribe 1.7.1 – Safer settings and smoother dictation recovery

**Save & Apply reports what was actually saved.** If prompts or vocabulary cannot be written, macOS and Windows show a partial-save warning instead of a success confirmation. Unsaved drafts remain available for another attempt. A failed save also prevents a macOS relaunch.

**Windows protects unsaved settings when closing.** Closing the window, pressing Escape, or choosing Close offers Save, Discard, or Cancel when changes are pending. A failed or incomplete save leaves the window open.

**Errors stay readable without delaying safe retries.** Error messages remain visible for four seconds. On Windows, completed error paths allow another dictation before the message disappears; warm capture waits for audio cleanup. Old stop callbacks and reset timers cannot take over a newer recording.

**macOS saves transcript history in the background.** Ordered history writes and their timing diagnostics no longer run on the UI thread. Clear History respects pending saves, and normal quit and update-restart paths finish accepted writes before exiting. History retention, audio buffers, and provider timeouts are unchanged.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.7.1.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.7.1-Local.zip`.
