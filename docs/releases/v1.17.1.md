**Release Date:** 2026-11-04

PulseScribe 1.17.1 – Picks up quieter speech

**Picks up quieter speech.** Voice detection now recognizes speech about a third quieter than before, on macOS and Windows, so soft-spoken dictation is less likely to be treated as silence.

**Livelier overlay.** The wave in the overlay moves more for the same voice, so quiet speech is clearly visible. The wave's maximum height is unchanged.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.17.1.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.17.1-Local.zip`.
