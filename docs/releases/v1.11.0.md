**Release Date:** 2026-11-03

PulseScribe 1.11.0 – A clearer setup wizard

**The setup wizard now looks like Settings.** A sidebar lists all five steps, marks the ones you finished and lets you click back to them. Each step has a short title and one line of explanation, and the footer keeps Back and Next in the same place.

**Choices are easy to see.** Fast, Private and Advanced are rows you select, and the one you picked stays marked. Fast asks for a Deepgram key right away if none is stored.

**One hotkey to get started.** The Hotkey step offers a few common choices and a custom shortcut. The wizard sets up one hotkey; if you already use two, they stay until you pick a row, and Settings → General still manages both.

**Permissions and your setup at a glance.** Permissions and the final review show small status badges instead of colored text, with "Allow…" only where access is missing. The review ends with how to dictate using your hotkey.

**A simpler practice test.** "Try it" shows one prompt and a transcript box with its status. It stays safe: nothing is pasted.

**Windows:** the wizard has the same layout, is now in English like Settings, and its "Open Settings…" button opens Settings again. A first run sets up one hotkey (Hold Ctrl+Win).

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.11.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.11.0-Local.zip`.
