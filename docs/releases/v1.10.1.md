**Release Date:** 2026-11-02

PulseScribe 1.10.1 – You can see it working

**A soft light now sweeps across the overlay while PulseScribe works.** While preparing, transcribing and refining, a light moves along the line, so you can tell at a glance that your dictation is being processed. With Refine on, it runs over the step in progress. It stops as soon as the result appears.

**Reduce motion is respected.** With "Reduce motion" on macOS or animation effects turned off on Windows, the line stays static as before.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.10.1.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.10.1-Local.zip`.
