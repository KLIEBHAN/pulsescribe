**Release Date:** 2026-11-11

PulseScribe 1.20.1 – Streaming preview: transcript sooner, quiet speech kept

Both changes apply when Live preview is set to **streaming model** (macOS).

**The transcript is ready when you stop after a pause.** Until now Whisper only started when you stopped, so every dictation waited for one full Whisper pass. Whisper now also transcribes in the background at speech pauses while the streaming model shows the text. If you stop about a second after your last word, the transcript is already there: 0.02 s instead of 0.40 s on an M6 with turbo. With Whisper passes slowed to 0.9 s, the duration measured on an M5, the wait fell from 0.92 s to 0.26 s. Stopping right after your last word takes as long as before. This needs the MLX backend and a model other than large, large-v2 or large-v3; with those Whisper still starts at the stop.

**One case can wait longer.** If you pause, add a short remark and stop at once, the background pass from the pause may still be running. In our test with the slowed passes one of four such recordings waited 0.4 s longer.

**Quiet dictation is no longer discarded.** A recording whose level stays below the speech threshold used to end as "No speech". PulseScribe now transcribes it if the streaming model recognized words in it. In a test with quiet sentences, 8 of 8 were transcribed instead of none, while noise, clicks and silence were discarded as before. Quiet speech of about two seconds or less is often too short for the streaming model and is still discarded.

<!-- install-notes -->

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.20.1.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.20.1-Local.zip`.
