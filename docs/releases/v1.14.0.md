**Release Date:** 2026-11-03

PulseScribe 1.14.0 – Pick the server model from a list

**Server model picker.** In the own server mode, the Server Model field in Settings → Providers now lists the models your server offers, for example `whisper-1`, `large-v3-turbo` and `large-v3` on a PulseScribe-compatible Whisper server. The list loads when Settings opens, after you change the Server URL, or with **Refresh**. You can still type any model name, also when the server offers no list.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.14.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.14.0-Local.zip`.
