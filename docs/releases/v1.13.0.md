**Release Date:** 2026-11-03

PulseScribe 1.13.0 – Server model and microphone changes without restart

**Microphone changes without restart (macOS).** Plugging in or removing a microphone, for example when docking your MacBook, no longer requires quitting PulseScribe. The next recording uses the current devices, and Settings lists newly connected microphones. Before, recordings could fail with "Internal PortAudio error" until a restart.

**Your chosen microphone in every mode (macOS).** The microphone selected in Settings is now used for Local, OpenAI, Groq and own server recordings too; before, it only applied to Deepgram streaming.

**Choose the server model.** In the own server mode, Settings → Providers has a Server Model field, for example `large-v3` for the slower, more accurate Whisper model. Leave it empty to keep sending `whisper-1`.

Use **Check for Updates…** in the macOS menu bar or Windows tray to install this version.

<!-- install-notes -->

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, check that the DMG matches its entry in `SHA256SUMS.txt` (`shasum -a 256 PulseScribe-1.13.0.dmg`), then run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

This skips Gatekeeper's check; the app uses a stable PulseScribe signing certificate but is not notarized. When updating from 1.6.0 or earlier, grant Microphone, Accessibility and Input Monitoring permissions once more. Updates from 1.6.1 or newer retain the existing permission identity.

Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.13.0-Local.zip`.
