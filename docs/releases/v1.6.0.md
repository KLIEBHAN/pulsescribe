**Release Date:** 2026-10-13

PulseScribe 1.6.0 – Update window and Local Whisper updates on Windows

Updates now appear in their own window with download progress, scrollable release notes and an install button.

Windows Local Whisper installations receive updates again.

<!-- install-notes -->

The update window opens once when a new version is found, without taking focus from the app you dictate into. “Check for Updates…” in the macOS menu bar or Windows tray opens it at any time. Every release now includes the Windows Local Whisper package, and the standard installer removes Local Whisper leftovers after a successful installation.

For a new macOS install, copy `PulseScribe.app` to Applications. If macOS blocks the app, run:

```bash
xattr -dr com.apple.quarantine /Applications/PulseScribe.app
```

The app is ad-hoc signed and not notarized. Configuration in `~/.pulsescribe` is preserved. The standard Windows installer is API-only; the Local Whisper package is attached as `PulseScribe-Setup-1.6.0-Local.zip`.
